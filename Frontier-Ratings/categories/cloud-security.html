Why it matters to a bank

  • Misconfigured cloud resources expose customer data
  • The bank lacks a single view of risk across several cloud providers
  • Vulnerable or compromised workloads run undetected

  8. 2026-03-19 · security incident Aqua Security
    Aqua's open-source Trivy scanner and GitHub Actions compromised in supply chain attack

    Aqua disclosed that attackers who had obtained a privileged token from Trivy's GitHub Actions environment in late February 2026 published a malicious Trivy v0.69.4 release on 2026-03-19 and redirected version tags of the trivy-action and setup-trivy GitHub Actions to code containing an infostealer. Malicious Docker Hub images followed on 2026-03-22 and internal repositories were made public. Aqua said an earlier credential rotation had been incomplete, that it engaged Sygnia for forensics, and that it had no indication its commercial products were affected. The advisory is rated critical (CVE-2026-33634).
