  • Sensitive internal content is indexed by a third party

    AWS Quick adds enterprise guardrails in preview

    AWS announced on 2026-11-20 a preview of enterprise guardrails for AWS Quick, letting administrators apply content filters, denied topics, blocked words, prompt-attack detection and controls for selected personal data types to user prompts, by user, identity-provider group or account default, with a detect-only mode. AWS said the preview is open to select customers on the Professional and Enterprise plans. Amazon Web Services (vendor, retrieved 2026-11-22, opens in new tab)

  2. 2026-11-20 · rebrand Writer
    Writer renames WRITER AI Studio to Control Center

    Writer said on its blog on 2026-11-20 that WRITER AI Studio is now called Control Center, reflecting its role as the admin hub for agent governance after agent building moved into the main app. The navigation is reorganised into seven sections covering usage, activity logs, build governance, integrations, security, billing and settings. Writer said existing configurations and permissions are unchanged, and announced no pricing change. Writer (vendor, retrieved 2026-11-22, opens in new tab)
