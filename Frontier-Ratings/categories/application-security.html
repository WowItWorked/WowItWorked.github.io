Why it matters to a bank

  • Vulnerable code and dependencies reach production
  • The bank cannot say which applications contain a newly disclosed vulnerable component
  • Secrets are committed to source code

Where the category is heading

  1. 2026-09-11

    The EU Cyber Resilience Act's reporting obligations began to apply on 11 September 2026, the European Commission said: manufacturers of products with digital elements sold in the EU must report actively exploited vulnerabilities and severe incidents through ENISA's single reporting platform, with an early warning within 24 hours and full notification within 72 hours. The Act's main obligations apply from 11 December 2027. European Commission (regulator or standards body, retrieved 2026-11-20, opens in new tab)

  2. 2025-12-09

    Checkmarx acquired Tromzo, a start-up founded in 2021 whose AI agents filter false positives, prioritise vulnerabilities and generate code fixes, as reported by BankInfoSecurity on 9 December 2025. Checkmarx's chief executive told the outlet he expected further acquisitions. BankInfoSecurity (ISMG) (independent press, retrieved 2026-11-20, opens in new tab)

  3. 2025-06-24

    Snyk announced on 24 June 2025 that it was acquiring Invariant Labs, an ETH Zurich spin-off researching AI agent security whose Guardrails product inspects agent behaviour and scans MCP servers for vulnerabilities. Terms were not disclosed. Snyk (vendor, retrieved 2026-11-20, opens in new tab)

  4. 2025-02-05

    Semgrep raised a US$100 million Series D led by Menlo Ventures, bringing its total funding to US$204 million, as reported by SecurityWeek on 5 February 2025. SecurityWeek (independent press, retrieved 2026-11-20, opens in new tab)

  5. 2025-01-06

    Veracode announced on 6 January 2025 that it had acquired certain assets of Phylum, including its technology for detecting and blocking malicious open-source packages, to be integrated into Veracode's software composition analysis product. Terms were not disclosed. Veracode (vendor, retrieved 2026-11-20, opens in new tab)

Recent events

  1. 2026-11-17 · launch GitHub
    GitHub puts on-demand secret scanning in Copilot's security review into public preview

    GitHub's changelog of 17 November 2026 says Copilot's security review now runs GitHub's secret scanning detectors on code changes before merge, in public preview, across Copilot CLI, the Copilot app, Copilot SDK integrations and Copilot code review. The entry says the feature is off by default, is not yet in VS Code, and that scans consume AI credits under the Secret Protection AI Credit SKU. GitHub (vendor, retrieved 2026-11-22, opens in new tab)

  2. 2026-11-12 · partnership Endor Labs
    Endor Labs integrates with OpenAI's Daybreak Defense Factory and Codex Security

    Endor Labs said in a blog post dated 12 November 2026 that OpenAI had announced an integration between Endor Labs and its Daybreak Defense Factory. According to the post, Endor Labs findings and reachability evidence are passed to Codex Security, which implements and tests fixes that Endor Labs then checks against customer policy before human review. The post says the integration is live. Endor Labs (vendor, retrieved 2026-11-22, opens in new tab)

  3. 2026-11-12 · launch Semgrep
    Semgrep launches its Agentic AppSec Platform for securing agent-written code

    Semgrep announced on 2026-11-12 an Agentic AppSec Platform made up of Guardian (scanning agent-written code before commit), Agentic Workflows, the Mandoline program analysis tool, a Context Layer and the Semgrep MCP server, with bring-your-own-key, single-tenant and EU-region deployment options. Semgrep's post says the platform is available to its customers from that date, while the Context Layer is in private beta. Performance figures in the post are Semgrep's own. Semgrep (vendor, retrieved 2026-11-22, opens in new tab)

  4. 2026-11-11 · certification Black Duck Software
    Polaris listed on FedRAMP Marketplace as in process; not yet authorised

    Black Duck announced that the Polaris Platform is listed on the FedRAMP Marketplace in the initial implementation phase and that it is pursuing FedRAMP 20x Class C certification with an assessment against the Rev5 Moderate baseline. The product is not yet authorised. Black Duck Software (vendor, retrieved 2026-11-20, opens in new tab)

  5. 2026-11-10 · launch Cycode
    Cycode adds persistent memory to its Maestro security agent

    A Cycode blog post dated 10 November 2026 introduced memory for Maestro, the agent within the Cycode platform. The post describes an always-on store for preferences, rules and team vocabulary and a recalled store for factual context, which users can view, change or delete. It does not say whether the feature is generally available or in preview. Cycode (vendor, retrieved 2026-11-22, opens in new tab)

  6. 2026-11-05 · leadership change Checkmarx
    Checkmarx appoints Kobi Sivilya as chief information security officer

    Checkmarx announced on 2026-11-05 the appointment of Kobi Sivilya to oversee security, IT and business applications. The release quotes chief executive Sandeep Johri. Checkmarx (vendor, retrieved 2026-11-20, opens in new tab)

  7. 2026-10-13 · partnership SonarOpenAI
    Sonar joins OpenAI's Daybreak cyber partner programme

    Sonar announced it had joined OpenAI's Daybreak Defense Network, giving it access to OpenAI's cyber models, which it plans to use in the SonarQube Hunter Agent. Sonar (vendor, retrieved 2026-11-21, opens in new tab)

  8. 2026-09-29 · launch Sonar
    SonarQube Server 2026.5 LTA released with agents for self-managed deployments

    Sonar announced general availability of SonarQube Server 2026.5 LTA, making Sonar Vortex, the Hunter Agent and the Remediation Agent purchasable with the Enterprise and Data Center editions, with central governance of the LLMs they use. Sonar (vendor, retrieved 2026-11-21, opens in new tab)
