Why it matters to a bank

  • Online banking, payment and API channels are taken offline or slowed by denial-of-service attacks
  • Web applications and APIs are exploited, or abused through their business logic, before flaws can be fixed
  • Automated traffic takes over customer accounts, scrapes data or commits fraud while looking like real customers

Where the category is heading

  1. 2026-11-22

    Products that were once bought separately are now sold as one cloud-delivered service. Cloudflare's documentation describes protection against network-layer and HTTP-layer denial-of-service attacks that is switched on by default, with rules that adapt to a site's normal traffic, and links its firewall to bot and client-side products. Akamai's App & API Protector page describes a web application firewall, API discovery, bot controls and application-layer DDoS defence in one product that tunes itself. F5's documentation describes a firewall with API security and API endpoint learning. Radware's 2025 annual report describes plans that add API discovery, bot management and client-side protection to a cloud firewall, names Akamai, Imperva, Netscout, Cloudflare, F5 and AWS as competitors, notes competition from security built into the public clouds, and reports new add-ons aimed at generative AI traffic.
